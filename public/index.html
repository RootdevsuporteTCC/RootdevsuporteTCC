<HTML>

HTML (HyperText Markup Language / Linguagem de Marcação de Hipertexto) é a linguagem usada para estruturar uma página web, com textos, imagens e links. Ele é o esqueleto da internet, dizendo ao navegador como organizar as informações mostradas na tela.

#CSS

CSS (Cascading Style Sheets / Folhas de Estilo em Cascata) é a linguagem de design usada para controlar a aparência visual de páginas na web. Enquanto o HTML define a estrutura básica, o CSS é responsável pelas cores, fontes, tamanhos, espaçamentos, layout responsivo e animações do site.

JAVASCRIPT()

O JavaScript é uma linguagem de programação que dá vida aos sites e aplicativos. Enquanto o HTML define a estrutura e o CSS cuida do visual, o JavaScript é responsável pela interatividade. Ele permite criar animações, validar formulários, alterar conteúdos na tela sem recarregar a página e etc.
