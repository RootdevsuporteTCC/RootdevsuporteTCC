COMO EXECUTAR O ROOT DEV

1. Instale o Node.js e o MySQL.

   Utilize, de preferência, as mesmas versões do computador original.
   Para consultar as versões do Node.js e do npm no computador original:
   node --version
   npm --version

2. Extraia a pasta do projeto.

   Mantenha os arquivos package.json e package-lock.json.

3. Abra um terminal dentro da pasta que contém package.json e execute:
   npm ci

   Esse comando instala as dependências e recria node_modules.
   É necessário ter acesso à internet durante a instalação.

4. Execute o arquivo SQL do projeto no MySQL para criar o banco.

   Para levar as contas, os comentários e os logs do computador original,
   exporte a estrutura e os dados pelo MySQL Workbench.
   Um SQL contendo apenas a estrutura cria as tabelas vazias.

5. Crie o arquivo .env na mesma pasta de package.json e index.js.

   O nome deve ser exatamente .env, sem a extensão .txt.

   Preencha:

   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD="SUBSTITUA_PELA_SENHA_DO_MYSQL"
   DB_NAME=mydb
   PORT=8000
   SESSION_SECRET=SUBSTITUA_PELA_CHAVE_GERADA

   Como obter cada informação:

   DB_HOST:
   Use localhost se o MySQL estiver instalado nesse computador.

   DB_PORT:
   Consulte o campo Port da conexão no MySQL Workbench.
   Normalmente é 3306.

   DB_USER:
   Consulte o campo Username da conexão no MySQL Workbench.
   Pode ser root ou outro usuário configurado.

   DB_PASSWORD:
   Use a senha desse usuário do MySQL, definida durante a instalação.
   Não é necessariamente a mesma senha do computador original.

   DB_NAME:
   Use o nome do banco criado pelo SQL. Neste projeto, usamos mydb.

   PORT:
   É a porta escolhida para executar o site. Pode manter 8000.

   SESSION_SECRET:
   Gere uma chave executando no terminal:
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

   Copie o resultado e substitua SUBSTITUA_PELA_CHAVE_GERADA.

   Para consultar host, porta e usuário no Workbench, clique com o botão
   direito na conexão e selecione Edit Connection.
   A senha não é exibida nessa tela.

6. Configure o envio de e-mail no .env.

   Copie do .env do computador original as variáveis utilizadas pelo
   serviço de e-mail, mantendo os mesmos nomes.

   Se utilizar a mesma conta remetente, mantenha as configurações
   e a senha de aplicativo dessa conta.

   Essa configuração é necessária para a recuperação de senha funcionar.

7. Inicie o servidor:
   node index.js

8. Abra no navegador:
   http://localhost:8000

   Se PORT tiver outro valor, utilize essa porta no endereço.

9. Antes da apresentação, teste:
   - Cadastro e login.
   - Edição de perfil.
   - Acesso administrativo.
   - Conteúdos e comentários.
   - Recuperação de senha.
