# INTRODUÇÃO AO JAVASCRIPT

Chegou a hora de dar **vida** ao seu site! 

Enquanto o **HTML** define a estrutura (o esqueleto) e o **CSS** cuida do visual (a pele e as roupas), o **JavaScript (JS)** é o responsável pelo comportamento (os músculos e o cérebro).

## O que o JavaScript pode fazer?

O JavaScript é uma linguagem de programação completa que roda diretamente no navegador do usuário. Com ele, você pode:

* **Mudar o conteúdo HTML:** Alterar textos e imagens na tela com um clique.
* **Mudar os estilos CSS:** Esconder elementos, mudar cores, criar animações.
* **Validar formulários:** Conferir se o usuário digitou uma senha forte antes de enviar os dados.
* **Criar interatividade:** Fazer menus aparecerem, criar jogos, alertas e muito mais, tudo isso **sem precisar recarregar a página**!

Prepare-se para transformar páginas estáticas em aplicativos web dinâmicos e interativos.
